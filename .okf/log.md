Fixed client-side in `src/client/index.ts`'s `send()`: the in-flight pane/element is now recorded (and the box/chip shown, chip reading `→ <title> · sending…`) synchronously before the `/prompt` fetch is issued, not after its response arrives; a non-200 response or network error clears it again. `startInflight` gained a `chipSuffix` parameter (default `'working…'`) and a `hidden` parameter (kept for the screenshot capture window below); `renderInflightChip` gained the same suffix parameter. A second-order race surfaced by the fix itself: a herdr:status push can now arrive and settle (blocked/idle) the pane before the `/prompt` response itself resolves, so the response handler's own "Sent to …" toast could clobber the settle toast already shown - fixed with an `inflightSettled` flag, set by `settleInflightFinished`/`settleInflightBlocked` and checked before showing "Sent to …" or retargeting. Screenshot capture (above) reuses the same pre-fetch tracking but keeps the box/chip hidden (`startInflight(..., hidden: true)`) until the response settles, so the client's own overlay never lands inside the captured crop. `e2e/status.spec.ts` gained a `waitForInflight` helper (polls `window.__herdr.inflight()`) used before pushing test events in both tests, replacing a single-shot, non-retried check; `sendPrompt` now waits for a preselected agent option before sending, closing a separate, unrelated race where `Enter` could land before `GET /state` resolved and fall back to clipboard mode instead of posting `/prompt` at all (only surfaced under `--repeat-each` stress). Verified with `npx playwright test e2e/status.spec.ts --repeat-each=8 --workers=1`, 100% green across repeated runs.

Multi-select: shift+click while picking adds an element to the selection (up to 5 total) instead of finalizing the pick; a plain click always finalizes. `PromptRequest` gained `extras?: ElementInfo[]` (up to 4, validated in `src/http.ts` the same way as `element`, any invalid item rejects the whole request). `composePrompt`/`renderAttachment` in `src/compose.ts` render each extra as a numbered `Element N:` block (inline) or `## Element N` section (attachment), rewriting the extra's picked-marker to `data-herdr-picked="N"`; `postPrompt` absolutizes every extra's hint.
